# 🚀 FreelanceCRM

Современная CRM-система для фрилансеров в стиле Notion. Управляйте клиентами, проектами, задачами, финансами и налогами в одном месте.

![Vite](https://img.shields.io/badge/Vite-6.4-purple)

## ✨ Возможности

### 📊 Дашборд
- Обзор ключевых метрик бизнеса
- Статистика по выбранному периоду (день/неделя/месяц/год/произвольный)
- График динамики финансов
- Ближайшие дедлайны и напоминания

### 👥 Управление клиентами
- База клиентов со статусами (активный/неактивный/лид)
- Список проектов каждого клиента со статусами
- Быстрая генерация документов:
  - 📄 Акты выполненных работ
  - 📋 Договоры подряда
  - ✉️ Письма клиентам
- Скачивание и отправка документов

### 📁 Проекты
- Канбан-доска (бэклог → в работе → на проверке → завершено)
- Табличный вид
- Приоритеты и бюджеты
- Привязка к клиентам

### ✅ Задачи
- Управление задачами с циклическим статусом
- **Навигация**: клик по проекту/клиенту ведёт на соответствующую страницу
- Приоритеты и дедлайны
- Пометки источников (вручную/AI/авто/бриф)

### 📅 Календарь
- Визуализация дедлайнов проектов, задач и контента
- Цветовое кодирование по типам событий
- 🔔 Система напоминаний за N дней до события
- Просроченные и срочные задачи

### 📝 Контент-план
- Планирование публикаций (посты, сторис, статьи, видео)
- **Автоматизация**: AI-генерация контента с пометками 🤖
- Статусы: запланировано → в работе → готово → опубликовано
- Привязка к проектам и клиентам
- Отдельный визуал для автоматического контента

### 💰 Финансы
- Учёт доходов и расходов
- **Группировка по периодам**: дни, недели, месяцы, годы
- Визуальный график и таблица
- Расходы по категориям
- Пометки источников (вручную/авто/импорт)

### 🧾 Налоги и платежи
- Поддержка систем: УСН 6%, УСН 15%, НПД, ОСНО, Патент
- Расчёт налогов помесячно/поквартально/за год
- Учёт страховых взносов
- График платежей с датами
- Настраиваемые ставки

## 🛠 Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS 4** — стилизация
- **LocalStorage** — хранение данных

## 🚀 Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/freelance-crm.git
cd freelance-crm

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать для продакшена
npm run build
```

## 📦 Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Sidebar.tsx      # Боковая панель навигации
│   ├── Dashboard.tsx    # Главная страница
│   ├── Clients.tsx      # Управление клиентами
│   ├── Projects.tsx     # Управление проектами
│   ├── Tasks.tsx        # Управление задачами
│   ├── Calendar.tsx     # Календарь
│   ├── ContentPlan.tsx  # Контент-план
│   ├── Finances.tsx     # Финансы
│   ├── TaxCalculator.tsx # Калькулятор налогов
│   ├── DocumentGenerator.tsx # Генерация документов
│   └── DateRangeSelector.tsx # Выбор периода
├── types.ts             # TypeScript типы
├── data.ts              # Начальные данные и storage
├── utils.ts             # Утилиты и хелперы
├── App.tsx              # Главный компонент
└── main.tsx             # Точка входа
```

## 💾 Хранение данных

Все данные сохраняются в **localStorage** браузера. При первом запуске загружаются демо-данные для ознакомления.

## 🎨 Особенности UI

- Минималистичный дизайн в стиле Notion
- Адаптивная боковая панель
- Модальные окна для форм
- Плавные анимации и переходы
- Цветовое кодирование статусов и приоритетов

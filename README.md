# 🚀 FreelanceCRM

Современная CRM-система для фрилансеров в стиле Notion. Управляйте клиентами, проектами, задачами, финансами и налогами в одном месте.

## ✨ Возможности

### 📊 Дашборд
- Обзор ключевых метрик бизнеса
- Статистика по выбранному периоду (день/неделя/месяц/год/произвольный)
- График динамики финансов
- Ближайшие дедлайны и напоминания

### 👥 Управление клиентами
- База клиентов со статусами (активный/неактивный/лид)
- Список проектов каждого клиента со статусами
- Быстрая генерация документов:
  - 📄 Акты выполненных работ
  - 📋 Договоры подряда
  - ✉️ Письма клиентам
- Скачивание и отправка документов

### 📁 Проекты
- Канбан-доска (бэклог → в работе → на проверке → завершено)
- Табличный вид
- Приоритеты и бюджеты
- Привязка к клиентам

### ✅ Задачи
- Управление задачами с циклическим статусом
- **Навигация**: клик по проекту/клиенту ведёт на соответствующую страницу
- Приоритеты и дедлайны
- Пометки источников (вручную/AI/авто/бриф)

### 📅 Календарь
- Визуализация дедлайнов проектов, задач и контента
- Цветовое кодирование по типам событий
- 🔔 Система напоминаний за N дней до события
- Просроченные и срочные задачи

### 📝 Контент-план
- Планирование публикаций (посты, сторис, статьи, видео)
- **Автоматизация**: AI-генерация контента с пометками 🤖
- Статусы: запланировано → в работе → готово → опубликовано
- Привязка к проектам и клиентам
- Отдельный визуал для автоматического контента

### 💰 Финансы
- Учёт доходов и расходов
- **Группировка по периодам**: дни, недели, месяцы, годы
- Визуальный график и таблица
- Расходы по категориям
- Пометки источников (вручную/авто/импорт)

### 🧾 Налоги и платежи
- Поддержка систем: УСН 6%, УСН 15%, НПД, ОСНО, Патент
- Расчёт налогов помесячно/поквартально/за год
- Учёт страховых взносов
- График платежей с датами
- Настраиваемые ставки

## 🛠 Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS 4** — стилизация
- **LocalStorage** — хранение данных

## 🚀 Быстрый старт

```bash

git clone https://github.com/your-username/freelance-crm.git

# Установить зависимости
```

## 🌐 Деплой на GitHub Pages

### Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на [github.com](https://github.com)
2. Нажмите **New repository** (зелёная кнопка)
3. Заполните:
   - **Repository name**: `freelance-crm` (или другое)
   - **Description**: `CRM-система для фрилансеров`
   - Выберите **Public** (для GitHub Pages)
   - ❌ **НЕ** ставьте галочку "Add a README"
4. Нажмите **Create repository**

### Шаг 2: Загрузите код

```bash
# В папке с проектом
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/freelance-crm.git
git push -u origin main
```

### Шаг 3: Включите GitHub Pages

1. Откройте репозиторий на GitHub
2. Перейдите в **Settings** (настройки)
3. В меню слева выберите **Pages**
4. В разделе **Build and deployment**:
   - **Source**: выберите **GitHub Actions**
5. ✅ Готово! Workflow уже настроен в `.github/workflows/deploy.yml`

### Шаг 4: Дождитесь деплоя

1. Перейдите во вкладку **Actions**
2. Вы увидите запущенный workflow "Deploy to GitHub Pages"
3. Дождитесь завершения (обычно 1-2 минуты)
4. ✅ Ваш сайт будет доступен по адресу:
   ```
   https://ВАШ_ЛОГИН.github.io/freelance-crm/
   ```

### 🔄 Автоматические обновления

Теперь при каждом `git push` в ветку `main` сайт будет автоматически пересобираться и деплоиться!

### 🐛 Если что-то не работает

1. Проверьте вкладку **Actions** — там видны логи сборки
2. Убедитесь, что репозиторий **Public** (для бесплатного GitHub Pages)
3. Проверьте, что в **Settings → Pages** выбрано **GitHub Actions**
4. Подождите 5-10 минут после первого push (GitHub Pages может задерживаться)
